# レポート
用紙サイズ／文字サイズ
‒ A4縦／11ポイント
• ページ数について
‒ レポートにプログラムを掲載するときは、説明に
必要な最小部分のみとすること
‒ 単にプログラムや実行例が長いだけの、長文レポ
ートを減点します

# 説明書の記載内容
• テンプレートを参照
‒ 学生番号／氏名，グループ
‒ 自己評価（S, A, B, C, D）／作業時間
‒ メンバーの相互評価
• 自分も含めた全体の作業量を100としたときの各自の作業量
• 例）
‒ A: 30
‒ B: 30
‒ C(自分): 40
‒ 課題毎の説明
• プログラム，実行例，評価，考察・感想
‒ 参考文献／謝辞

# 考察と感想
• 考察
‒ 当初の目論見通り成功したのか、
それとも失敗したのかを結論づける
• 当初の予定に対してどのような結果になったのかを
評価データ等をふまえて議論
‒ 成功しても失敗してもその理由を説明
• 失敗したり、時間不足で断念した場合は、
成功に向けた方策を示すこと
• 感想
‒ 本演習に関する所感を記載

# レポートについての補足事項
• 説明書に書かなければ評価されない
‒ 「プログラムを読めば分かる」というのはNG
‒ 特に自分が担当した部分を説明すること
• 理由を書くこと
‒ 「Xである。理由はYである。」のように
• 論旨明快かつ短い報告書が良い
‒ 同じ内容なら、より短い報告書が良い
‒ プログラムを転記しただけの報告書は、
良い評価を得られない
