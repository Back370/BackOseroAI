## 3. 数値検算（自分で再計算して確認）
- ノード削減率: (534,944,374-326,263,489)/534,944,374 = 0.3901 → 39.0% ✓
- 時間削減率 : (58.141-47.844)/58.141 = 0.1771 → 17.7% ✓
- nps(なし)  : 534,944,374/58.141 = 9.20e6 ✓
- nps(あり)  : 326,263,489/47.844 = 6.82e6 ✓

## 4. 考察の論点（正直な分析）
- 期待通り(好影響): 段階別評価＋bookでベースライン比 圧勝（vs base 100%/26.33石差、
  p26x42 vs base 83.33%）。位置評価のみ→機動力/確定石/フロンティアの動的評価が効いた。
- 期待ほどでない/逆説: bookで**nps自体は 9.20→6.82 Mnps に低下**した。
  理由: bookで序盤の「分岐が広く軽い」ノードをスキップするため、実際に探索するのは
  中終盤の重い局面に偏り、1ノードあたりの平均コストが上がる。
  → ただし「総ノード-39%・総時間-17.7%・序盤安定・勝ち越し」で導入目的は達成。
  npsは速度の代理指標にすぎず、bookは「探索しない最適化」なのでnps低下は想定内。
- 教訓(課題1由来): 機動力を過信したφ評価は対強相手で失敗した(課題1e, 30%)。
  大会版は段階別に重みを分け、終盤のみ石数(確定)を重くして回避した。
- 今後: 置換表(同一局面の再利用)→NegaScout→並列化→終盤完全読み。
